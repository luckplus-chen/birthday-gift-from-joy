# 生日网站 · 内容填写表（v2）

**整个流程是这样的：**

```
输密码 → 读信（滚轮往下滑）→ 把信卷起来
       → 划火柴照亮黑暗 → 发现蛋糕（蜡烛我已经点好了）
       → 许愿 → 吹灭 → 生日快乐
       → 摸黑找东西 → 找到礼物盒 → 拆开 → 安装包弹出来
```

**怎么用：**
1. 在下面 `- 字段:` 后面写内容
2. `>` 开头的灰行是提示，不用管也不用删
3. 填完运行一次：

```bash
node build-content.js
```
